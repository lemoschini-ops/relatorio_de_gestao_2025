# Relatório de Gestão 2025 — UFSCar

Painel institucional com 993 séries qualificadas, gráficos de evolução de 2020–2025 e filtros por assunto, campus, curso e programa.

Aplicação estática. Publicação pelo GitHub Pages a partir da branch `main`, pasta `/ (root)`.

Para executar localmente: `python -m http.server 8000` e abrir `http://localhost:8000`.

Os gráficos preservam os valores exatos e indicam os períodos não qualificados como N/D. Painéis fixos comparáveis da pós-graduação estão identificados no painel.

A versão de publicação contém os indicadores e as visualizações qualificadas; consulta documental, contadores, cabeçalho, rodapé e menu superior foram retirados.
